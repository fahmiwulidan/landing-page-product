## Ringkasan Proyek

**NEXA IoT - Product Landing Page** adalah platform *landing page* interaktif berbasis web yang dirancang khusus untuk mempresentasikan layanan riset, pembuatan perangkat keras (*hardware*), pengembangan *firmware* mikrokontroler, hingga solusi dashboard analitik awan (Cloud IoT) secara presisi dan terintegrasi.

> [!NOTE]
> Proyek ini dikembangkan menggunakan *pure client-side web stack* (HTML5, CSS3, Vanilla JS) yang teroptimasi, ultra-ringan, serta responsif di berbagai platform.

---

## Teknologi Utama

| Layer | Teknologi | Deskripsi |
| :--- | :--- | :--- |
| **Structure** | HTML5 | Semantik markup terstruktur untuk navigasi & layanan IoT |
| **Styling** | CSS3 (`styles.css`) | Custom Futuristic Dark UI, Flexbox, & CSS Variables |
| **Interactivity** | JavaScript (`script.js`) | Logika interaktif antarmuka & manipulasi DOM |

---

## Fitur Unggulan

- **Desain Futuristic Dark-Theme** — Visual antarmuka bertema teknologi modern dengan warna aksen neon yang estetis.
- **Showcase Layanan R&D IoT** — Presentasi terstruktur untuk perancangan skematik PCB, firmware mikrokontroler, telemetri real-time, dan analitik awan.
- **Call-to-Action (CTA) Interaktif** — Tombol navigasi cepat untuk konsultasi proyek IoT dan pengujian *live telemetry lab*.
- **Performa Ringan (Zero Dependency)** — Pengunduhan halaman super cepat tanpa ketergantungan *framework* luar.
- **Layout Responsif Sepenuhnya** — Tampilan yang fleksibel dan nyaman diakses melalui smartphone, tablet, maupun desktop.
